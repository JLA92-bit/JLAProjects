# Credits

Puzzle Cascade deliberately avoids third-party art/sound packs so the whole
game ships as source code with no binary asset licensing to track. Everything
visual and audible is either generated in code at runtime or comes from the
two dependencies below.

## Libraries

- **[Three.js](https://threejs.org/)** (`vendor/three.module.min.js`) - MIT
  License, see `vendor/THREE-LICENSE`. Used for every game's 3D rendering
  (tiles, gems, maze corridors, jigsaw pieces, etc). Vendored locally (not
  loaded from a CDN) so the game works fully offline, which matters for the
  planned Capacitor/APK build.

## Fonts

- **[Baloo 2](https://fonts.google.com/specimen/Baloo+2)** and
  **[Nunito](https://fonts.google.com/specimen/Nunito)** - both SIL Open
  Font License 1.1, loaded from Google Fonts (`shared/css/theme.css`). No
  attribution is legally required under OFL, but it's credited here anyway.
  If you need the game fully self-hosted (no Google Fonts request), download
  both families and swap the `@import` in `theme.css` for local `@font-face`
  rules - everything falls back to system sans-serif cleanly if the request
  fails or is blocked.

## Art

- **No external art, sprite, or photo assets are used anywhere.** All visual
  content is generated by code:
  - Every tile, gem, wall, card, and piece is a procedurally-built Three.js
    mesh (extruded rounded rectangles, octahedra, boxes, cones) with plain
    color materials defined in each game file.
  - The Jigsaw puzzle's "photo" (games/08-jigsaw) is painted at runtime onto
    a `<canvas>` (gradient sky, sun, layered mountains, stars) - it is not a
    scraped or stock image.
  - Icons are native emoji glyphs, rendered by the browser/OS's own emoji
    font - no image files are shipped for them.
  - The app icon (`icons/*.svg`) is a small hand-written SVG (four rounded
    squares + a circle), not third-party artwork.

## Sound

- **No audio files are used anywhere.** `shared/js/sound-manager.js`
  synthesizes every sound effect and the ambient background music at
  runtime with the Web Audio API (oscillators + gain envelopes). This keeps
  the game a few KB of text instead of megabytes of audio, and again means
  zero licensing surface and full offline support.

## If you want to swap in real art/sound packs later

The brief's original suggestion - [Kenney.nl](https://kenney.nl) (CC0),
[OpenGameArt.org](https://opengameart.org) (filter CC0/CC-BY), and
[Freesound.org](https://freesound.org) (CC0, check per file) - is still a
great source if you'd rather have hand-drawn sprite art or real audio
samples. If you do:

1. Drop files under `assets/images/` and `assets/audio/` (already present,
   currently empty).
2. Replace the relevant Three.js material/texture calls in each
   `games/*/*.js` file, or point `SoundManager` at `<audio>`/decoded buffers
   instead of its oscillator functions.
3. Add an entry here noting the exact pack, URL, and license, and whether
   the license requires attribution (CC0 doesn't; CC-BY does).
