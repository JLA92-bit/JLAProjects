## Graphics

Sprites are cropped directly from the **Sprout Lands - Sprites - Basic pack**,
by **Cup Nooble** (`cupnooble.carrd.co`, Discord: `cup_nooble`).

Used in `farm-game/assets/`:

- `grass1.png`, `grass2.png` — grass ground tiles
- `dirt_tilled.png` — tilled soil
- `path.png` — dirt path
- `water1.png`, `water2.png` — animated water
- `fence_post.png`, `fence_rail.png` — fence border
- `house.png` — farmhouse/barn
- `crop_stage0.png` .. `crop_stage3.png` — wheat growth stages
- `player.png` — the 4-direction character walk spritesheet
- `tool_hoe.png` — HUD tool icon (currently unused, kept for future HUD polish)

be redistributed or resold, even modified — only projects built with it may

Because of the non-commercial restriction, **this game and its hosted
GitHub Pages build are non-commercial**. If you ever want to sell this game

## Other packs supplied but not (yet) used

Three more free packs were supplied during development and extracted for
reference, but nothing from them is in `assets/` yet:

- **Cute Fantasy Free** — non-commercial license, no redistribution/resale.
  Has its own grass/water/farmland tiles, a player sheet, animals, and
  basic enemies — could supplement or replace Sprout Lands assets later.
- **Farm RPG FREE 16x16 - Tiny Asset Pack** — an itch.io freebie; license
  terms weren't included in the download, so treat it as non-commercial /
  no-redistribution until confirmed otherwise. Has a taller-proportioned
  character, farm animals, a house, and a 6-stage crop sheet.
  (These files aren't in `assets/` yet since Sprout Lands covered the same
  needs first — but they're relatively higher quality if v2 wants to
  upgrade the look.)
- **Pixel Crawler - Free Pack** — a dungeon-crawler pack (characters, mobs,
  weapons, dungeon tilesets). Not farm-themed; would mainly be useful if
  the game grows enemies/combat/dungeons later.

None of these raw pack archives are committed to this repository — see
`assets/README.md` for why, and how to re-supply them if a future session
needs to pull more sprites from them.
