# Credits

## Code

Written from scratch for this project: `index.html`, `style.css`, `game.js`.

## Graphics

No external image assets are used in this build — all graphics (tiles,
fence, water, crops, player) are drawn procedurally with the Canvas 2D API.
See `assets/README.md` for why, and how to swap in real sprite packs later.

If/when real assets are added:

- **Tiles / crops / fences**: intended source is Kenney's ["Tiny
  Farm"](https://kenney.nl/assets/tiny-farm) pack, CC0 (public domain, no
  attribution required).
- **Player character**: intended source is the [Universal LPC Spritesheet
  Character
  Generator](https://liberatedpixelcup.github.io/Universal-LPC-Spritesheet-Character-Generator/).
  Output from that tool is licensed CC-BY-SA and/or GPL depending on the
  specific body parts/clothing layers selected, per the Liberated Pixel Cup
  and OpenGameArt contributors. When a real spritesheet is generated and
  committed, list the exact asset pieces used and their individual
  attributions here, as required by those licenses.
